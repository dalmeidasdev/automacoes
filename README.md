========================================[Auto Sites v1.0]========================================

O meu primeiro processo de automação, como o nome sugere ele automatiza o acesso aos principais sites que eu uso, sendo eles o github, youtube e simplesmente o chrome, como já entra na minha conta e o acesso já é salvo eu só coloquei o link do site e ele já abria sem precisar de login

Eu aida nessa altura não estudei tratamento de erros, POO, etc. (eu tenho um repositório com as coisas que eu já estudei no meu github se quiser acompanhar o meu progresso atual https://github.com/dalmeidasdev/estudos-python), logo essa v1 é bem simples só com o básico do que eu já sei

Funcionalidades v1.0:

- Uso da biblioteca pyautogui para automatizar as tarefas
- Funções para a abertura dos sites
- Menu simples
- Utils para captura da posição do mouse
- Separação dos arquivos em pasas visando modularização
