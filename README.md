## 🤖 Sobre o uso de IA
O código deste repositório é escrito por mim, **sem IA**, porque o objetivo é treinar minhas habilidades. Se em algum momento eu usar IA, vou registrar aqui como e onde.

## 📦 Projetos

### Auto Sites v1.0 — `auto-sites-v1/`
Meu primeiro projeto de automação. Abre os sites que mais uso (GitHub, YouTube e Chrome) a partir de um menu. Como o navegador já está logado na minha conta, basta o link do site e ele abre sem pedir login.

**Funcionalidades**
- Automação das tarefas com a biblioteca `pyautogui`
- Funções para abrir cada site
- Menu simples no terminal
- Utilitário para capturar a posição do mouse
- Código separado em pastas, pensando em modularização

**Limitações conhecidas**
- Ainda não tem tratamento de erros nem orientação a objetos, porque são assuntos que ainda não estudei
- Depende de o navegador estar com a conta já logada

## 🚀 Como usar
Requisitos: Python 3 e Windows.

```bash
git clone https://github.com/dalmeidasdev/automacoes.git
cd automacoes/auto-sites-v1
pip install pyautogui
python main.py   
```
